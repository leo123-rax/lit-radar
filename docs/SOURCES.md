# Source catalog

*Authoritative list of every adapter in `litradar/sources/` plus the planned ones. Live checks were
made on 2026-10-17 from a residential IP with the `lit-radar/0.1` User-Agent and no credentials
unless stated. "Fact-checked" marks rows whose load-bearing claim was re-verified by an independent
agent against primary documentation or a repeat live call (see `RESEARCH.md`). Per-adapter notes
written by the builders live in `docs/sources/`. Status cells were re-checked against `litradar/pipeline.py`
and `config/radar.yaml` on 2026-10-18.*

**Status vocabulary.** `wired` = runs in the weekly pipeline today (on by default unless the cell says
otherwise). `built` = adapter, offline tests and notes exist and the pipeline can run it, but it is off by
default; today that is only J-STAGE, for its API terms (`sources.jstage.enabled: true` or `--sources jstage`
turns it on). `needs key`
= works only with a free key. `blocked` = the route answers 403/429/404 to scripts. `planned` =
researched, no code yet. `excluded` = will not be built, with the reason.

## 6. Not used, and why

* **Publisher logins / personal subscriptions**: reading rights only; no automated access
  (`LEGAL.md`, `SUBSCRIPTIONS.md`).
* **Google Scholar**: robots.txt and Terms; no code path.
* **Altmetric**: free tier is for university scientometrics researchers only and the keyless
  endpoint returned 403 from the probe egress; a commercial contract or nothing.
* **Scopus, Web of Science, Dimensions, Lens**: institution-licensed; commercial and investment use
  excluded from free tiers; no self-serve price.
* **Crunchbase, PitchBook, CB Insights, Dealroom, Tracxn**: no self-serve API tier; free substitutes
  (ROR new company records, SBIR/STTR, RePORTER, CT.gov `INDUSTRY` sponsors, openFDA applicants)
  cover new-entrant detection.
* **PatentsView PatentSearch API**: paused since 2026-03-20; Google Patents on BigQuery (1 TiB/month
  free) or EPO OPS instead, when patents are added.
* **Vendor investor-relations RSS**: 25 of 27 returned 403/404; wires and EDGAR exhibits instead.
* **Vendor publication pages** (10x Genomics behind a Vercel checkpoint; Illumina, Olink, PacBio,
  Oxford Nanopore JavaScript-only): only Bruker Spatial Biology and Parse Biosciences expose a
  WordPress REST `publication` endpoint; those two are planned as weekly polite pulls.
